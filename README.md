# Portfolio Site

A personal portfolio website that presents my profile, skills, experience, projects, education and certifications in one place.

Live: https://tanya-singh-portfolio-dusky.vercel.app

## Sections

Hero · About · Skills · Experience · Projects · Education · Certifications · Contact

## Tech Stack

- **Frontend:** React, Tailwind CSS, Framer Motion, Three.js, Lenis, Radix UI
- **Deployment:** Vercel

## Run Locally

```bash
cd frontend
yarn install
yarn start
```

Portfolio content is stored in `frontend/src/data/resume.js`.
